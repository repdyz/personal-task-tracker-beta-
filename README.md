# Personal Task Tracker

A simple personal task management web application built with:

- HTML, CSS, JavaScript
- FastAPI
- PostgreSQL

## Features

- Add tasks
- View all tasks
- Filter tasks by status
- Mark tasks as completed
- Delete tasks
- REST API
- PostgreSQL database
